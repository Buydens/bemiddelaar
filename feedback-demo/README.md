# Werkruimte feedbackdemo

Deze map is de afzonderlijke publicatiebundel. Upload uitsluitend de inhoud van
deze map naar een statische host.

## Privacy

- Alle profielnamen zijn expliciete demolabels: `Demo Profiel A` tot en met H.
- Alle bemiddelaars zijn demolabels.
- E-mailadressen gebruiken het gereserveerde domein `example.com`.
- Telefoonnummers zijn ongeldige demoformaten met prefix `+32 000`.
- De map bevat geen oudere prototypepagina's met realistischer namen.

## Publiceren

`index.html` is het startbestand. Er is geen buildstap of servercode nodig.
Upload de volledige inhoud van deze map en behoud de bestandsnamen.
